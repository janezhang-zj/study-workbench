# 忆 · 学习工作台（主动回忆 + 间隔重复）

一个单文件 HTML 学习工作台，解决「白天学了很多、晚上一复习发现没记住多少」的问题。

核心逻辑是**主动回忆（Active Recall）**：录入时只记关键词，复习时先只看线索、逼自己回想，想不起来再揭晓当时的画板原图。配合**间隔重复（Spaced Repetition）**，把每条内容按 当天 → 隔天 → 第 3 天 → 第 7 天 自动排期。

## 特点

- **单文件、零依赖**：整个应用就是一个 `study-workbench.html`，双击用浏览器打开即可，不需要安装、不需要联网。
- **数据全在本地**：所有内容存在浏览器 `localStorage`，不请求任何服务器、不上传。可一键导出 JSON / 文本摘要备份，也可导入还原。
- **手写 + 键盘混合录入**：无限画布，鼠标/触控笔涂写，双击生成可拖拽缩放的文本框，适合记公式、画图、写要点。

## 功能

### 1. 录入画板

- 无限延伸画布：滚轮平移、抓手工具拖动、`Ctrl + 滚轮` 缩放、双指缩放，可「适应」回到内容。
- 手写：6 种画笔颜色、粗细调节、橡皮（擦整笔）、撤销（`Ctrl + Z`）、清空。
- 文字：双击空白处或点「+ 文字」新建文本框，直接打字；支持拖拽、缩放、删除。
- 完成录入时自动从文字中提取 3–5 个核心关键词作为回忆线索（可手动增删）；纯手写无文字时会提示手动填写标题/关键词。
- 可打科目标签（英语 / 高数 / Python / 政治 / 专业课，支持自定义）。

### 2. 今日复习

- 按间隔规则自动筛出今天该复习的条目，标注轮次：今日新学 / 次日 / 第 3 天 / 第 7 天，逾期会标记天数。
- 默认**只显示关键词线索**，不显示原图；点「查看答案」才展开当时的画板快照（手写 + 文字），支持全屏查看。
- 「记住了」推进到下一间隔（走完第 7 天即标记为已掌握）；「没记住」重置为明天再来。状态与时间自动记录。
- 可按标签筛选今日清单。

### 3. 统计与打卡

- 今日待复习 / 今日已复习 / 今日学习时长 / 连续打卡天数。
- 学习时长趋势（近 7 天、近 8 周），各标签复习完成率。
- GitHub 风格打卡热力图（近 20 周，颜色深浅代表当天学习时长），历史明细可按标签筛选。
- 顶栏一键打卡，自动累计连续天数。

## 使用

```bash
# 直接打开
双击 study-workbench.html

# 或者用任意静态服务器
python -m http.server 8000
# 然后访问 http://localhost:8000/study-workbench.html
```

> 想用 GitHub Pages 在线访问，把文件重命名为 `index.html` 并在仓库 Settings → Pages 里开启即可。

## 数据说明

- 存储位置：浏览器 `localStorage` 的 `sy_workbench_v1` 键，容量上限约 5 MB（手写笔画会占用空间，可在「数据管理」里查看占用）。
- 换浏览器、换设备、清理浏览数据都会导致数据丢失，**请定期用「导出学习记录（JSON）」备份**。
- `file://` 直接打开与部署到网址属于不同的存储来源，数据互不相通，可用 JSON 导入迁移。

## 浏览器支持

Chrome / Edge / Safari / Firefox 最新版本，桌面与手机浏览器均可使用（手写支持触屏与压感笔）。
